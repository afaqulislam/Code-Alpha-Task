## SonicWave -- Audio Player

<img src="https://img.shields.io/badge/HTML5-E34F26?style=flat-square&logo=html5&logoColor=white" alt="HTML5">
<img src="https://img.shields.io/badge/CSS3-1572B6?style=flat-square&logo=css3&logoColor=white" alt="CSS3">
<img src="https://img.shields.io/badge/JS-F7DF1E?style=flat-square&logo=javascript&logoColor=black" alt="JS">

</div>

> A sleek, modern audio player with glassmorphism card design, animated CSS visualizer bars, spinning disc album art, and full playback controls.

| Feature | Details |
|---------|---------|
| **Shuffle & Repeat** | 3 repeat modes plus shuffle toggle |
| **Volume Control** | Slider with mute toggle |
| **Seek Bar** | Draggable thumb scrubber with time display |
| **Playlist** | 3-track list with duration display |
| **Keyboard Shortcuts** | Space, Arrow keys, M, S, R, N, P |
| **Touch Support** | Swipe and touch gestures on mobile |
| **Visualizer** | 20-bar CSS-only audio visualizer |
| **Animations** | Spinning disc, pulse glow on play |

## CalcX Pro -- Smart Calculator

<img src="https://img.shields.io/badge/HTML5-E34F26?style=flat-square&logo=html5&logoColor=white" alt="HTML5">
<img src="https://img.shields.io/badge/CSS3-1572B6?style=flat-square&logo=css3&logoColor=white" alt="CSS3">
<img src="https://img.shields.io/badge/JS-F7DF1E?style=flat-square&logo=javascript&logoColor=black" alt="JS">
<img src="https://img.shields.io/badge/License-MIT-blueviolet?style=flat-square" alt="MIT">

</div>

> A professional-grade calculator with slide-out history panel, infix-to-postfix expression evaluation, dual themes, and glassmorphism design.

| Feature | Details |
|---------|---------|
| **Dual Themes** | Dark and Light mode with localStorage persistence |
| **History Panel** | Slide-out panel storing last 20 calculations |
| **Expression Parser** | Safe infix-to-postfix evaluation engine |
| **Keyboard Support** | Full number pad plus operators and Enter |
| **Error Handling** | Shake animation on invalid expressions |
| **Responsive** | Works down to 310px screen width |
| **Animations** | Entry animation, button press scales |
| **Glass UI** | Frosted glass card with gradient accents |

## Lumina -- Image Gallery

<img src="https://img.shields.io/badge/HTML5-E34F26?style=flat-square&logo=html5&logoColor=white" alt="HTML5">
<img src="https://img.shields.io/badge/CSS3-1572B6?style=flat-square&logo=css3&logoColor=white" alt="CSS3">
<img src="https://img.shields.io/badge/JS-F7DF1E?style=flat-square&logo=javascript&logoColor=black" alt="JS">

</div>

> An immersive image gallery with Ken Burns zoom effect, lightbox viewer, like system with floating heart particles, mouse parallax, and autoplay mode.

| Feature | Details |
|---------|---------|
| **Gallery** | 10-image showcase with smooth transitions |
| **Lightbox** | Fullscreen viewer with prev/next navigation |
| **Like System** | Heart button with floating particle animation |
| **Auto-Play** | Slideshow mode with 3s interval |
| **Dual Themes** | Dark and Light mode with localStorage persistence |
| **Ken Burns** | Subtle zoom effect on active image |
| **Mouse Parallax** | Image follows cursor on hover |
| **Touch Swipe** | Swipe navigation in gallery and lightbox |
| **Keyboard** | Arrow keys, F, Space, L shortcuts |

<div align="center">

## Design Principles

</div>

| Principle | Description |
|-----------|-------------|
| **Glassmorphism** | Frosted-glass cards with depth and blur |
| **Ambient Orbs** | Floating gradient blobs for atmosphere |
| **Micro-motion** | Hover lifts, press scales, spring easing |
| **Dark-first** | Dark mode as default with light alternative |
| **Responsive** | Fluid layouts from 310px to 4K |
| **Accessible** | Keyboard navigation and ARIA labels |
| **Zero Deps** | Pure HTML, CSS, JS -- nothing else |
